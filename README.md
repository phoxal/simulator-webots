# Historical Phoxal Webots simulator

This repository retains the earlier Webots controller source and artifacts for reference.
It is retired from active Phoxal simulation and does not publish new releases.
Use the [native simulator](https://github.com/phoxal/simulator#readme) for current simulation and the [Cargo tool](https://github.com/phoxal/cargo#readme) for robot preparation and scenario commands.

The retained source depends on its original SDK and Webots installation.
It is not qualified against the current SDK, and its old launch commands are not part of the current developer workflow.
Existing registry archives and checksums remain unchanged.
Historical source, models and generated changelog records are preserved.
